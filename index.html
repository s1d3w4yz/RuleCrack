Rule Chain Lab

A password-cracking rule is a chain of small steps — capitalize, substitute, append, swap, reject — applied to a word in order. Build one below, watch each step fire, and see how reordering, adding or removing a step changes the result.

  • Hashcat syntax default Unambiguous and the de facto standard. Most published rule lists use it, and John the Ripper runs it byte-for-byte identically in its hashcat-compat mode, so it's portable.
  • John's native syntax special cases Only when hashcat can't express what you need, like pluralization or John's own character classes.
Target:

Paste a .rule file (or a John List.Rules section) and check every line against a real parser, not a guess. Fix a broken line inline or in the chain builder, delete what you don't want, then export the cleaned file.

  • Pick the syntax first required The same letter can mean two different things in hashcat versus John's native grammar (p, R, L, v, +/-), so a file's dialect can't be auto-detected. You know which engine it's for — say so below.
  • Blank lines and comments kept Blank lines and # comments pass through untouched.
