Password Cracking Rule Chain Lab

Password-cracking tools like hashcat and John the Ripper don’t only try words from a list: they can also be told to apply rules to each word — capitalize it, add a 1 at the end, swap a for @ — to guess the variations people really use. A rule is a chain of small steps run in order. Build one below, watch each step fire, and see how reordering, adding or removing a step changes the result. Positions count from 0, in bytes (é is 2 bytes). Use this only on systems you are authorized to test.

  • Hashcat syntax default Unambiguous and the de facto standard. Most published rule lists use it, and John the Ripper can run it in its hashcat-compat mode, so it's portable.
  • John's native syntax special cases Only when hashcat can't express what you need, like pluralization or John's own character classes.
Target:

Paste a .rule file (or a John List.Rules section) and check every line against a real parser, not a guess. Fix a broken line inline or in the chain builder, delete what you don't want, then export the cleaned file.

  • Pick the syntax first required The same letter can mean two different things in hashcat versus John's native grammar (p, R, L, v, +/-), so a file's dialect can't be auto-detected. You know which engine it's for — say so below.
  • Blank lines and comments kept Blank lines and # comments pass through untouched.

03 Step chain

Steps run top to bottom, so order changes the output. Use the arrows to move a step and watch the trace change. Hover over a step to see its part of the rule line. Alt+↑/↓ move · Delete remove · Ctrl+Z undo

Reject steps don't transform the word — they decide whether it survives (e.g. "reject unless length ≥ 8"); once one rejects, the chain stops.
Memory steps (M 4 6 X Q) save a copy of the word and use it again later in the same rule. For example, M u 4 turns abc into ABCabc. Q rejects the word if it equals the saved copy.

Keyboard shortcuts & accessibility

Press ? anywhere outside a text box to open this, and Esc to close it.

Keyboard

Tab Shift+Tab
Move between controls. The first Tab on the page shows skip links (to the rule line, step chain, trace, batch test and cheat sheet).
Space
On a step's checkbox: turn that step on or off. Its token in the rule line is struck through while it is off.
Alt+↑ Alt+↓
With a step's checkbox or buttons focused: move that step up or down. Focus stays on it.
Delete
With a step's checkbox or buttons focused: remove the step. Focus moves to the next one.
Ctrl+Z ⌘+Z
Undo the last deleted step (also the Undo button in the notice). Inside a text box, it undoes your typing instead.
Esc
Clear the cheat sheet search box, or close this window.

Mouse & touch

Drag
Reorder steps by dragging the dotted handle on a step's left edge. The ↑ ↓ buttons do the same without dragging.
Hover or focus
On a step, a trace row, or a token in the rule line: the matching step card, trace row and token light up together. Putting the text cursor inside a token does the same, which also works on touch screens.
Click
An example in the cheat sheet adds it to the rule line. A ↑ trace button in the batch test loads that word into section 01.
Expand
Each list is a fixed-height box so the page stays on one screen. Expand shows all of it.

Display & accessibility settings

Dark · Light · Auto
Auto follows your system's light or dark setting (dark if it doesn't say). Remembered in this browser.
A  A  A
Three text sizes; the whole page scales. Remembered.
Link highlights
Turn off the hover, focus and cursor linking between steps, trace and rule line.
Scroll to match
Stop lists from scrolling to the linked item while keeping the highlights. Needs Link highlights on.
Wrap long lines
In the batch test: wrap long entries (default) or keep each on one line and scroll sideways.
Reduced motion
If your system asks to reduce motion, animations are off, scrolling is instant, and the two link switches start off (you can turn them on).

Screen readers & colour

Announcements
Moves, deletes, copies, the chain's result and the cheat sheet's match count are spoken. Every control has a name, and the toggle buttons report whether they are on.
Not colour alone
Changed characters in the trace are underlined as well as coloured. Hashcat-only operators carry an HC tag and John-only ones a J tag.
